A full-stack CRUD application built using React, Node.js, Express, and MongoDB.

## Features
- Add user
- View user list
- Delete user
- Clean and responsive UI
- Frontend connected with backend APIs

## Tech Stack
- Frontend: React, CSS
- Backend: Node.js, Express
- Database: MongoDB
- Version Control: Git & GitHub
